# The Hailo AI SW Suite ships TensorFlow 2.12, which is compiled against the
# NumPy 1.x ABI. Under NumPy 2 every `import tensorflow` dies with
# "ImportError: numpy.core._multiarray_umath failed to import", which breaks the
# DALI TensorFlow plugin build in `docker/hailo/Dockerfile` and every Hailo
# conversion at runtime.
numpy<2

# `luxonis-ml[data]` requires `numpy~=2.2` from 0.9.1 on, so 0.9.0 is the newest
# release this image can take. Pinning it also keeps the resolver from
# backtracking through every `luxonis-ml` and `onnx-graphsurgeon` release
# looking for a NumPy 1.x combination, which does not terminate in practice.
#
# Both lines can go once a luxonis-ml release accepts NumPy 1.x again or the
# suite ships a NumPy 2 compatible TensorFlow. Until then, raising the
# `luxonis-ml` floor in `requirements.txt` fails this build with a resolution
# error rather than silently breaking TensorFlow.
luxonis-ml==0.9.0
